# Susejing Hub

Centro del ecosistema **Susejing** para [Kino](https://github.com/kinotvapp/kino-light): todos tus plugins en un solo lugar.

## Qué hace (v0.1.0 — Fase 1)

- Lista los plugins de Susejing por categoría (video, imagen y estilo, lectura, tracking)
- Muestra cuáles tienes instalados
- **Instalar** o **Abrir** con un toque
- Accesos rápidos a AniJing, Gallery y MangaTrack

## Instalar en Kino

1. Ajustes ▸ Plugins ▸ **+**
2. Escribe: `Susejing/Susejing-Hub`
3. Agregar → Instalar
